# 교육·인턴 모집 이메일 감시기

SEMI Korea Program을 포함한 기존 9개 교육·인턴십 사이트, 링커리어 인턴, 고용24 반도체 KDT를 매일 한국시간 09:17, 13:17, 18:17에 확인합니다. 학교 4개 게시판은 11:47, 15:47에 확인합니다. 새 항목, 접수 시작, 일정 변경이 발견되면 저장소 소유자에게 GitHub 이슈를 할당합니다. GitHub의 이메일 알림 설정에 따라 이메일이 발송됩니다. SEMI·링커리어·고용24 KDT는 새 항목만 알립니다. 고용24 청년 일경험 포털은 지속적인 서버 연결 실패로 사용자 동의에 따라 비활성화했습니다.

교육·학교 감시는 macOS 15 표준 GitHub 실행기를 사용합니다. macOS 14 실행기 지원 종료로 2026-11-11 교체했습니다. 학교는 IPv4 HTTP 직접 조회를 재시도한 뒤 Playwright 요청으로 재시도하며, 모든 사이트는 첫 조회 실패 시 5초 후 한 번 더 수집합니다. 사이트별 성공 시각과 오류를 상태 파일/로그에 남기고, 일부 사이트가 실패하면 나머지 조회 결과를 저장하고 알림을 처리한 뒤 실행을 실패로 표시합니다. 로컬 검증은 `DRY_RUN=true`로 실행하면 상태 파일을 변경하지 않습니다.

비활성화된 청년 일경험 포털의 과거 조건은 참여기간 시작일 2026-12-01~2027-02-28, 지역·직무·유형 전체였습니다. 현재 이 포털의 공고는 확인하지 않습니다. 새 고용24 KDT 훈련 감시는 아래의 별도 조건을 사용합니다.

## 고용24 반도체 KDT 필터

AICT(차세대융합기술연구원) 공지 게시판도 교육 감시 시간 09:17·13:17·18:17에 확인합니다. 최신 목록(상단 고정 공지 포함)에서 제목에 G-SPEC/G SPEC이 포함된 새 게시글만 고유번호로 구분해 알립니다. 첫 실행은 기존 글을 기준선으로 저장합니다. 제목에 키워드가 없고 본문에만 있는 글은 대상이 아닙니다.

고용24 훈련 검색(`m.work24.go.kr`)에서 검색어 `반도체`, 전국, 오늘부터 1년 이내 개강예정 과정을 확인합니다. K-디지털트레이닝 일반·단기·AI캠퍼스는 포함하고 K-디지털기초역량훈련은 제외합니다. 각 과정의 시작일~종료일을 주말·휴일을 포함한 달력 일수로 계산하며, 시작일과 종료일을 포함해 70일 이하여야 합니다. 화면에 표시되는 실제 수업일수와는 다릅니다.

같은 과정의 다른 회차도 과정 ID+회차로 구분합니다. 날짜가 불명확하거나 모집중이 아닌 과정은 통과시키지 않습니다. 최초 실행은 현재 조건에 맞는 목록을 기준선으로 저장하고 이후 새 과정/회차만 기존 교육 감시 시간에 알립니다. 이전에 제외한 청년 일경험 포털(`yw.work24.go.kr`)은 계속 비활성 상태입니다.

## 링커리어 인턴 필터

링커리어 공개 인턴 목록을 같은 교육 감시 시간에 확인합니다. 최초 실행은 현재 모든 공개 공고의 ID만 기준선으로 저장하며 기존 글을 일괄 발송하지 않습니다. 이후 신규 공고는 상세 텍스트와 필요할 때 무료 Tesseract 한국어/영어 OCR로 확인합니다.

- 재학생/휴학생 지원 가능 또는 학력 무관이 확인돼야 하며 졸업(예정)자만 가능한 공고는 제외합니다.
- 명시된 근무기간이 3개월 이내여야 합니다. 기간 미상, 최소 3개월 이상, 3~6개월 등은 제외합니다. 시작일/방학 여부는 제한하지 않습니다.
- 근무지가 국내로 확인돼야 하며 해외 또는 위치 미상은 제외합니다.
- 반도체, 디스플레이, 자동차, 모빌리티, 방산, 항공우주, 기계, 로봇, 철강, 금속, 공공, 비영리 분야를 기업 업종/공고 제목/분류로 확인합니다.
- 자격·기간·분야를 확인할 수 없는 공고는 통과시키지 않습니다. OCR/규칙 기반 판독은 누락 가능성이 있으므로 완전한 채용자격 심사를 보장하지 않습니다. 이메일에 통과 근거를 함께 표시합니다.

신규 공고는 한 번에 최대 120건을 판정하고 나머지는 다음 실행에 이어서 처리합니다. 확인한 공고 ID를 저장해 같은 공고를 반복 알리지 않습니다. 별도 AI API나 유료 OCR을 호출하지 않습니다.

## 슈퍼루키·슥삭 인턴 필터

두 사이트도 교육 감시 시간(09:17·13:17·18:17)에 확인합니다. 슈퍼루키는 인턴·국내 17개 지역과 사용자가 선택한 생산관리/공정/품질, 생산/제조/설비/조립, 자동차/기계, 전기/전자/제어, 반도체/디스플레이, 금속/철강, 조선/항공/우주 직무 코드로 검색합니다. 슥삭은 체험형 인턴과 개발·엔지니어링/설계·제조/생산으로 검색하며 상세 직무도 재확인합니다.

두 사이트 모두 재학생/휴학생 지원 가능 또는 학력 무관, 국내 근무, 명시된 근무기간 3개월 이내가 확인돼야 합니다. 최소 3개월 이상·3~6개월·기간 미상·졸업자만 지원 가능한 공고는 제외합니다. 슈퍼루키 이미지 본문은 기존 무료 한국어 OCR을 사용합니다. 영문·이미지·모호한 자격 표현은 누락될 수 있습니다. 첫 실행은 기존 공고 ID를 기준선으로 저장하고 이후 새 공고만 같은 이메일 경로로 보냅니다. 별도 AI API나 유료 서버는 사용하지 않습니다.

## 알림을 원하는 이메일로 받기

1. GitHub `Settings → Emails`에서 원하는 수신 주소를 추가하고 인증합니다.
2. GitHub `Settings → Notifications → Custom routing`에서 이 저장소의 알림을 그 주소로 지정합니다.
3. 이 저장소의 Watch 설정을 `All Activity`로 지정합니다.

GitHub 계정의 기본 이메일과 알림 수신 이메일은 달라도 됩니다. 이메일 주소나 비밀번호는 이 저장소 코드에 저장하지 않습니다.

## 실행 방식

- 첫 실행은 현재 목록을 기준선으로 저장하며 알림을 보내지 않습니다.
- 이후 새 과정, 모집전/접수대기에서 모집중/접수중으로 변경, 일정 변경 시에만 이슈를 생성합니다.
- 한 사이트가 연속 3회 실패한 경우 점검 필요 이슈를 생성합니다.
- OpenAI API와 Codex를 호출하지 않으므로 배포 후 OpenAI 사용량을 소비하지 않습니다.

Actions 탭에서 `교육 및 인턴 모집 감시` 워크플로를 선택한 후 `Run workflow`로 수동 테스트할 수 있습니다.
