# 교육·인턴 모집 이메일 감시기

9개 교육·인턴십 사이트를 매일 한국시간 09:00, 13:00, 18:00에 확인합니다. 새 항목, 접수 시작, 일정 변경이 발견되면 저장소 소유자에게 GitHub 이슈를 할당합니다. GitHub의 이메일 알림 설정에 따라 이메일이 발송됩니다.

## 알림을 원하는 이메일로 받기

1. GitHub `Settings → Emails`에서 원하는 수신 주소를 추가하고 인증합니다.
2. GitHub `Settings → Notifications → Custom routing`에서 이 저장소의 알림을 그 주소로 지정합니다.
3. 이 저장소의 Watch 설정을 `All Activity`로 지정합니다.

GitHub 계정의 기본 이메일과 알림 수신 이메일은 달라도 됩니다. 이메일 주소나 비밀번호는 이 저장소 코드에 저장하지 않습니다.

## 실행 방식

- 첫 실행은 현재 목록을 기준선으로 저장하며 알림을 보내지 않습니다.
- 이후 새 과정, 모집전/접수대기에서 모집중/접수중으로 변경, 일정 변경 시에만 이슈를 생성합니다.
- 한 사이트가 연속 3회 실패한 경우 점검 필요 이슈를 생성합니다.
- OpenAI API와 Codex를 호출하지 않으므로 배포 후 OpenAI 사용량을 소비하지 않습니다.

Actions 탭에서 `교육 및 인턴 모집 감시` 워크플로를 선택한 후 `Run workflow`로 수동 테스트할 수 있습니다.
